# Prototipo anterior en Flask

Esta carpeta conserva los archivos de la primera prueba de Inventario WM realizada con Flask.

Contenido:

- `app.py`: aplicación Flask anterior.
- `templates/`: páginas HTML del prototipo.
- `static/`: estilos del prototipo.

Este código se mantiene únicamente como referencia histórica. **No forma parte de la aplicación Laravel activa**, no debe utilizarse para iniciar el sistema actual y no debe mezclarse nuevamente con las carpetas principales.

La aplicación vigente se inicia desde la raíz del repositorio con:

```bash
php artisan serve
```
